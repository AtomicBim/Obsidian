## 1. О чем эта инструкция?
> - как получить доступ к Tangl Value,
> - как авторизоваться,
> - как открыть Tangl Value в **браузере**,
> - как открыть Tangl Value через **настольное приложение**.
## 2. Получение доступа к Tangl Value
Есть 2 варианта доступа:
1. **Через вашу корпоративную почту**

<a href="mailto:r.grigoriev@atomsk.ru?subject=Доступ%20к%20Tangl%20Value&body=Добрый%20день,%0A%0AПрошу%20предоставить%20доступ%20к%20Tangl%20Value.">Напишите заявку администратору Tangl в Outlook</a>, либо <a href="https://t.me/AtomicBIM" target="_blank">в Telegram</a>. Администратор создаст вам учетную запись, и предоставит права [*аудитора*](https://help.tangl.cloud/tangl/tangl-guide/roles.html), которые позволяют:
- просматривать BIM-модели,
- просматривать ведомости объемов.

> [!important] 
> *Аудитору* Tangl Value доступен **только для чтения**. Вы **не** сможете вносить изменения или **негативно** влиять на работу других пользователей.

Логин в Tangl Value - адрес вашей корпоративной почты. Проверьте её, туда придет уведомление от Tangl с предложением сменить пароль. **Не забудьте его поменять!**

2. **Через вашу личную почту**

Этот вариант менее предпочтителен, но возможен, если у вас нет корпоративной почты и возможности ее получить. Напишите заявку администратору <a href="https://t.me/AtomicBIM" target="_blank">в Telegram</a>, либо позвоните по телефону <a href="tel:89504674880" target="_blank">8-950-467-4880</a>. Остальные действия аналогично п. 1, только вместо корпоративной почты ваша личная.
## 3. Авторизация

Чтобы начать работать, вам нужно написать в строке поиска браузера
> <a href="https://value.tangl.cloud" target="_blank">value.tangl.cloud</a>
Программа работает в любом браузере, но лучше используйте Google Chrome.

При первом входе в Tangl Value вам будет предложено *авторизоваться*. Для этого введите адреса вашей электронной почту, которую вы указали администратору, и пароль, который вы ранее поменяли.

## 5. Работа в настольном приложении
Если вы хотите работать не в браузере, а с настольного приложения, <a href="mailto:help@it-ip.ru?subject=Нужно установить Tangl Value на компьютер&body=Добрый день,%0A%0AПрошу установить программу Tangl Value.%0A%0AУстановочный файл находится по этому пути: P:\03_БИБЛИОТЕКА\Revit_1_Данные\Tangl Platform\TanglValue.exe%0A%0AПосле установки прошу не отключаться, и запустить Tangl Value - возможно потребуется установка дополнительного ПО">напишите заявку в IT-IP</a>, или позвоните по внутреннему номеру 1999 с просьбой установить Tangl Value.

Ваши дальнейшие действия при работе с настольным приложением Tangl Value [описаны здесь](https://atom-bim.ru/Instruct/Tangl/%D0%98%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%86%D0%B8%D1%8F_Tangl_Value_v2.php?id=27&Razdel=6)

Использование настольного приложения имеет плюсы и минусы:

> [!success]
> - приложение работает стабильнее,
> - более привычный, минималистический интерфейс.

> [!missing] 
> - функции-новинки недоступны,
> - нужна постоянная помощь специалиста техподдержки,
> - приложение долго и часто обновляется,
> - разработчик больше не поддерживает настольное приложение.
