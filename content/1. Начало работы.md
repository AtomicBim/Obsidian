# 1. О чем эта инструкция?
> - как получить доступ к Tangl Value,
> - как авторизоваться,
> - как открыть Tangl Value в **браузере**,
> - как открыть Tangl Value через **настольное приложение**.
# 2. Получение доступа к Tangl Value
## 2.1. Через вашу корпоративную почту

Чтобы получить доступ, отправьте заявку администратору Tangl [на почту](mailto:r.grigoriev@atomsk.ru?subject=Доступ%20к%20Tangl%20Value&body=Добрый%20день,%0A%0AПрошу%20предоставить%20доступ%20к%20Tangl%20Value.), либо [в Telegram](https://t.me/AtomicBIM). Администратор создаст вам учетную запись и предоставит права [*аудитора*](https://help.tangl.cloud/tangl/tangl-guide/roles.html), которые позволяют:
- просматривать BIM-модели,
- просматривать ведомости объемов.

> [!important] 
> *Аудитору* Tangl Value доступен **только для чтения**. Вы **не** сможете вносить изменения или **негативно** влиять на работу других пользователей.

Логин в Tangl Value - адрес вашей корпоративной почты. Проверьте её, туда придет уведомление от Tangl с предложением сменить пароль. **Не забудьте его поменять!**
## 2.2. Через вашу личную почту

Если у вас нет корпоративной почты и возможности ее получить, отправьте заявку администратору [в Telegram](https://t.me/AtomicBIM), либо позвоните по телефону [8-950-467-4880](tel:89504674880).
# 3. Авторизация

Для начала работы, напишите в строку поиска браузера:
> [value.tangl.cloud](https://value.tangl.cloud)

> [!info] 
> Программа работает в любом браузере, но лучше используйте Google Chrome. 

При входе в Tangl Value вам будет предложено *авторизоваться*. Для этого введите адрес вашей электронной почты, которую вы указали администратору, и пароль, который вы ранее поменяли ⬇️.

# 4. Форматы работы в Tangl
## 4.1. Работа в браузере
Tangl Value доступен по адресу:
> [value.tangl.cloud](https://value.tangl.cloud)

> [!info] 
> Работайте с Tangl в браузере - это удобно и всегда доступно. Все [[index|инструкции]] на этом сайте относятся к веб-версии Tangl Value (Tangl Value WEB).
# 5. Работа в настольном приложении
Если вам удобнее работать в настольном приложении, [отправьте заявку в IT-IP](mailto:help@it-ip.ru?subject=Нужно%20установить%20Tangl%20Value%20на%20компьютер&body=Добрый%20день,%0A%0AПрошу%20установить%20программу%20Tangl%20Value.%0A%0AУстановочный%20файл%20находится%20по%20этому%20пути:%20P:\03_БИБЛИОТЕКА\Revit_1_Данные\Tangl%20Platform\TanglValue.exe%0A%0AПосле%20установки%20прошу%20не%20отключаться,%20и%20запустить%20Tangl%20Value%20-%20возможно%20потребуется%20установка%20дополнительного%20ПО), или позвоните по внутреннему номеру 1999 с просьбой установить Tangl Value. Работа с настольным приложением Tangl Value подробно описана [в этой инструкции](https://atom-bim.ru/Instruct/Tangl/%D0%98%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%86%D0%B8%D1%8F_Tangl_Value_v2.php?id=27&Razdel=6).

Плюсы и минусы настольного приложения:

> [!success]
> - приложение работает стабильнее,
> - более привычный, минималистический интерфейс.

> [!missing] 
> - функции-новинки недоступны,
> - нужна постоянная помощь специалиста техподдержки,
> - приложение долго и часто обновляется,
> - разработчик больше не поддерживает настольное приложение.
