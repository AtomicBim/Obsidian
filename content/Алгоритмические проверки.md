# Проверки
## КР
### 11. Фундаменты паркинга. Примыкание монолитных конструкций паркинга и дома выполнять через деформационный шов. Опирание дома и паркинга производить на отдельные фундаменты
> - определить наличие в модели "Группа модели" = "Стены монолитные", "Описание" = "Утепление"
> - есть -> выделить в модели
### 14. Все подземные конструкции. Все поверхности фундаментов, соприкасающиеся с грунтом, обмазать готовой гидроизоляционной битумно-полимерной мастикой в 2 слоя по готовому битумному праймеру
> - такая гидроизоляция не моделируется на М0
> - получить данные о всех текстовых примечаниях, размещенных на листах в модели
> - проанализировать с помощью LLM наличие упоминания о гидроизоляции
> - есть -> указать лист
### 15. Все подземные конструкции. На участке с пучинистыми грунтами преимущественно рассматривать свайный тип фундамента
> - т.к. требование локализовано под конкретную модель, искать наличие/отсутствие свайных фундаментов по группе модели и описанию
> - получить данные о всех текстовых примечаниях, размещенных на листах в модели
> - проанализировать с помощью LLM наличие упоминания о свайном типе фундамента под пучинистыми грунтами
> - есть -> указать лист и выделить свайные фундаменты
### 16. Наружные стены паркинга ниже отметки 0,000. При посадке фундаментов на суглинистые грунты, устройство полов выполнять в виде самонесущей полноценно армированной плиты толщиной 200 мм с опиранием на фундаментные ростверки
> - проверить наличие "Группа модели" = "Фундаменты монолитные", "Описание" = "Фундамент плитный" с толщиной 200 мм
> - дополнительно проверить самое нижнее "Группа модели" = "Перекрытия монолитные", "Описание" = "Плита перекрытия" с толщиной 200мм с параметром "Этаж", содержащим "-"
> - есть -> выделить в модели
### 17. Все подземные конструкции. При проектировании фундаментов количество перепадов принимать не более трех. При проектировании ленточных фундаментов расстояние между конструкциями применять более 200 мм, либо объединять конструкции
#### Первая проверка
> - выделить все элементы группы модели "Фундаменты монолитные"
> - определить количество различных нижних ординат *bounding box* горизонтальных элементов
> - если их больше 3х -> указать
#### Вторая проверка
> - проверить наличие "Группа модели" = "Фундаменты монолитные", "Описание" = "Фундамент ленточный
> - проверить в 2 захода минимальные расстояния - сперва через *bounding box*, потом через геометрию элементов
> - если есть отклонения от граничных условий -> указать
### 22. Внутренние стены паркинга. Проемы под ворота паркинга выполнять в монолитной стене.
- работа через подгрузку связи КР
- найти "ворота"
- определить основу
- определить взаимодействие основы и стены из связанной модели
- проверить Группа модели/Описание стены из связанной модели -> указать в модели
### 24. Фундаменты входных групп жилого дома. Ступени на входных группах и эвакуационных выходах из здания не предусматривать
> - имеются в виду твинблочные лестницы
> - найти их
> - определить принадлежность помещению из связанного файла
> - сделать вывод -> указать
### 25. Фундаменты входных групп жилого дома. Стены спусков в подвал выполнить из панелей несъемной опалубки «Филигран» по возможности
> - выделить филигран по Группа модели/Описание
> - проверить принадлежность филиграна помещениям спусков в подвал -> указать
### 26. Фундаменты входных групп жилого дома. По возможности ступени спусков в подвал выполнить из типовых заводских маршей
> - выделить лестничные марши сборные по Группа модели/Описание
> - проверить принадлежность лестничных маршей сборных помещениям спусков в подвал -> указать
### 38. Гидроизоляция стен подвальной части жилого дома. «Филигран» оклеечная гидроизоляция только стыков
> - получить данные о всех текстовых примечаниях, размещенных на листах в модели
> - проанализировать с помощью LLM наличие упоминания об оклеечной гидроизоляция стыков филигран
### 43. Наружные стены ниже отметки 0,000 жилого дома. Сборномонолитные в несъемной опалубке «Филигран». Несъемная опалубка «Филигран» содержит заполнение бетоном на щебне фракции 5-10
> - отфильтровать по параметру "Этаж" содержащим "-"
> - отфильтровать скриптом наружных стен
> - выбрать филигран по Группа модели/Описание
> - если вся выборка филигран -> ок, если нет -> уведомить
> - проверить материал слоя на наличие ключевых слов для щебня -> уведомить
### 44. Наружные стены ниже отметки 0,000 жилого дома. Панели «Филигран» выполнять без разрезки монолитными торцами внутренних стен
> - получить филигран по Группа модели/Описание
> - получить монолитные стены по Группа модели/Описание
> - получить взаимоперпендикулярные экземпляры стен
> - проверить сближение
### 46. Наружные стены паркинга ниже отметки 0,000. Стены паркинга выполнять панелями «Филигран»
> - отфильтровать по параметру "Этаж", содержащим "-"
> - отфильтровать скриптом наружных стен
> - выбрать филигран по Группа модели/Описание
> - если вся выборка филигран -> ок, если нет -> уведомить
### 47. Стены ЛЛУ жилого дома. Сборномонолитные в несъемной опалубке «Филигран».
> - выбрать филигран по Группа модели/Описание
> - отфильтровать по параметру "Этаж", не содержащим "-"
> - "раздуть" машинное помещения из связи вниз до 1 этажа
> - весь филигран принадлежит ему -> ок, если нет -> уведомить
### 49. Лотки в МОП жилого дома. Бетонные заводского изготовления производства «Берит» согласно альбому СП.ИЖБ.03. Лотки по возможности прикладывать только к филиграну.
> - выбрать лотки по Группа модели/Описание
> - проверить параметр, отвечающий за серию
> - т.к. лотки группируются в стояки, отобрать стояки в пределах этажа
> - выбрать филигран по Группа модели/Описание
> - отобрать филигран в пределах этажа
> - проверить ближайшую стену -> филигран ок, монолит не ок
### 50. Перекрытия жилого дома. В межквартирных коридорах предусмотреть уменьшение толщины плиты перекрытия до 160 мм для прокладки инженерных коммуникаций
> - "раздуть" МОП на каждом этаже
> - определить принадлежащее перекрытие по Группа модели/Описание
> - проверить толщину 160 мм -> ок, если нет -> уведомить
### 51. Декоративный элемент торца плиты перекрытия жилого дома	Несъемные железобетонные элементы торцов плит производства «Берит», согласно альбому СП.ИЖБ.06. Торцевой элемент с выступом за плоскость фасада не применять
> - выбрать лотки по Группа модели/Описание
> - проверить параметр, отвечающий за серию
### 52. Термовкладыши жилого дома. В местах прохода элементов молниезащиты минплита, в остальных случаях ППС14
> - выбрать термовкладыши по Группа модели/Описание
> - узнать у Дениса места прохода молниезащиты
> - проверить материал, отвечающий за серию -> уведомить
### 53. Лестничные марши и площадки типового этажа жилого дома	Сборный ж/б. производство «Берит» согласно альбому СП.ИЖБ.01 изм. 1, СП.ИЖБ.02 изм. 1. Просвет между маршами d = 180 мм
> - выбрать лестничные марши и площадки по Группа модели/Описание
> - отфильтровать по "Этаж" выше 1
> - проверить параметр, отвечающий за серию
> - выбрать лестничные марши, определить минимальное расстояние 180 мм -> ок, если нет -> уведомить
### 54. Ограждение лестничных маршей жилого дома. Металлическое, типовое, согласно альбому СП.ОГВ изм. 1 «Ограждение маршей внутренних лестниц». Ограждение выполнить непрерывным
> - лестничные марши по Группа модели/Описание
> - проверить параметр, отвечающий за серию
### 55. Лестничные марши и площадки 1 этажа жилого дома	Монолитные железобетонные
> - выбрать лестничные марши и площадки по Группа модели/Описание
> - отфильтровать по "Этаж" равен 1
> - проверить материал бетон -> ок, если нет -> уведомить
## АР
### 3. Система координат жилого дома. Проекты ст. П выполнять на геодезической съемке в системе координат МСК66, проекты ст. Р в системе г. Екатеринбурга.
> - не определить в Revit

### 4. Высота типового этажа жилого дома. Н = 2900 мм от перекрытия до перекрытия.
> - выполнять проверку в модели КР
> - получить этажи со второго по кровлю
> - определить кратчайшие расстояния между перекрытиями
> - вывести список расстояний
> - сравнить с 2900 - отписать какие не совпадают
