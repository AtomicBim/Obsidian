# О чем эта инструкция?
> - как получить доступ к Tangl Value,
> - как авторизоваться,
> - как открыть tangl value через **настольное приложение**,
> - как открыть tangl value в **браузере.**

## 1. Получение доступа к Tangl Value
Для работы с Tangl необходимо получить корпоративный доступ. Напишите заявку администратору Tangl <a href="mailto:r.grigoriev@atomsk.ru"> на корпоративную почту</a> либо в <a href="https://t.me/AtomicBIM" target="_blank">в Telegram</a>.
После обработки заявки вам будут предоставлены права *аудитора*, что позволит:
- просматривать BIM-модели,
- просматривать ведомости объемов.

> [!important] 
> Программа Tangl Value доступна **только для чтения**. Вы **не** сможете вносить изменения или **негативно** влиять на работу других пользователей.

Логином в Tangl является ваша корпоративная почта. После создания учетной записи администратором вы получите уведомление от Tangl на почту с предложением сменить пароль.
## 2. Авторизация
При первом входе в Tangl вам будет предложено *авторизоваться*. Для этого введите вашу корпоративную электронную почту и пароль.

Чтобы установить программу, напишите <a href="mailto:help@it-ip.ru?subject=Нужно установить Tangl Value на компьютер&body=Добрый день,%0A%0AПрошу установить программу Tangl Value.%0A%0AУстановочный файл находится по этому пути: P:\03_БИБЛИОТЕКА\Revit_1_Данные\Tangl Platform\TanglValue.exe%0A%0AПосле установки прошу не отключаться, и запустить Tangl Value - возможно потребуется установка дополнительного ПО">заявку в IT-IP (нажми на меня)</a>, или позвоните по внутреннему номеру 1999.

> [!important] 
> Инструкция по основным сценариям работы в настольном приложении находится на корпоративном сайте по ссылке 🔽
> [Переход на сайт atom-bim.ru_Основы Tangl Value](https://atom-bim.ru/Instruct/Tangl/%D0%98%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%86%D0%B8%D1%8F_Tangl_Value_v2.php?id=27&Razdel=6)

> [!missing] 
> - функции-новинки недоступны,
> - нужна постоянная помощь специалиста техподдержки,

## 4. Работа в браузере
Чтобы начать работать, вам нужно написать в строке поиска браузера
> <a href="https://value.tangl.cloud" target="_blank">value.tangl.cloud</a>
Программа работает в любом браузере, но лучше используйте Google Chrome.

> [!important] 
> Работайте с Tangl в браузере. Это удобно, всегда доступно и соответствует вашим потребностям.
