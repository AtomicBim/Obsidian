## 1. О чем эта инструкция?

> - как открыть Tangl Value в **браузере**.
## 2. Получение доступа к Tangl Value
Для работы с Tangl Value нужен корпоративный доступ. Чтобы его получить, <a href="mailto:r.grigoriev@atomsk.ru?subject=Доступ%20к%20Tangl%20Value&body=Добрый%20день,%0A%0AПрошу%20предоставить%20доступ%20к%20Tangl%20Value.">напишите администратору Tangl в Outlook</a>, либо <a href="https://t.me/AtomicBIM" target="_blank">в Telegram</a>.
Администратор предоставит вам права [*аудитора*](https://help.tangl.cloud/tangl/tangl-guide/roles.html), что позволит:
- просматривать BIM-модели,
- просматривать ведомости объемов.

> [!important] 
> *Аудитору* Tangl Value доступен **только для чтения**. Вы **не** сможете вносить изменения или **негативно** влиять на работу других пользователей.

Логином в Tangl Value является ваша корпоративная почта. После создания учетной записи администратором вы получите уведомление от Tangl на почту с предложением сменить пароль.
## 3. Авторизация
При первом входе в Tangl Value вам будет предложено *авторизоваться*. Для этого введите вашу корпоративную электронную почту и пароль.

## 4. Работа в настольном приложении
Чтобы установить программу на ваш компьютер, <a href="mailto:help@it-ip.ru?subject=Нужно установить Tangl Value на компьютер&body=Добрый день,%0A%0AПрошу установить программу Tangl Value.%0A%0AУстановочный файл находится по этому пути: P:\03_БИБЛИОТЕКА\Revit_1_Данные\Tangl Platform\TanglValue.exe%0A%0AПосле установки прошу не отключаться, и запустить Tangl Value - возможно потребуется установка дополнительного ПО">напишите заявку в IT-IP</a>, или позвоните по внутреннему номеру 1999.

> [!important] 
> Инструкция по основным сценариям работы в настольном приложении находится на корпоративном сайте по ссылке 🔽
> [Atom-bim.ru_Основы Tangl Value](https://atom-bim.ru/Instruct/Tangl/%D0%98%D0%BD%D1%81%D1%82%D1%80%D1%83%D0%BA%D1%86%D0%B8%D1%8F_Tangl_Value_v2.php?id=27&Razdel=6)

Использование настольного приложения имеет плюсы и минусы:

> [!success]
> - приложение работает стабильнее,
> - более привычный, минималистический интерфейс.

> [!missing] 
> - функции-новинки недоступны,
> - нужна постоянная помощь специалиста техподдержки,
> - приложение долго и часто обновляется,
> - разработчик больше не поддерживает настольное приложение.
## 5. Работа в браузере
Чтобы начать работать, вам нужно написать в строке поиска браузера
> <a href="https://value.tangl.cloud" target="_blank">value.tangl.cloud</a>
Программа работает в любом браузере, но лучше используйте Google Chrome.

> [!help] 
> Работайте с Tangl в браузере. Это удобно и всегда доступно. Все инструкции, которые вы здесь найдете относятся к работе с Tangl Value в браузере - Tangl Value WEB.
